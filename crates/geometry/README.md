# Poet geometry helpers

This internal Poet library supports existing authoring commands with reusable
double-precision vectors, transforms, curves, splines, intersections and profile
tessellation. It has no UI, document owner, source store or capability namespace.
It does not replace Poet's Tool-Chest, Manifolds, ContextRef or intent semantics.

The source was imported from the existing CADCraft geometry library under its
MIT option. The original MIT copyright and permission notice are retained in
LICENSE-MIT. Historical source comments remain unchanged for provenance. Exact
original/staged/imported hashes and the functional mapping are recorded in the
sibling spatial-authoring crate's provenance directory. Original repositories
and the earlier staging directory remain intact.
