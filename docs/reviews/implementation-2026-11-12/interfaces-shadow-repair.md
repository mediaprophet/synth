## Source cause and bounded provider fix

Existing etalon-render shaders/mesh.wgsl sampled3x3 PCF offsets using one central comparison depth. Its angular receiver bias0.0015*(1-NdotL) vanished near face-on lighting and did not represent the actual shadow-space slope/linear-filter footprint. Caster raster bias already used constant2 and slope1.5. Shadow maps use forward-Z (clear1, Less depth writer, LessEqual sampler), so comparison-reference bias is subtracted even if the main camera uses another depth convention.

Added provider shadow_receiver.wgsl and assembled it into MESH_WGSL. Both cascade receiver derivatives are computed at fragment entry, before alpha discard and varying cascade branches. A relative projected-Jacobian test yields depth change per shadow texel. Near-singular/nonfinite/grazing cases produce finite bounded values and select the existing angular fallback. Valid planes correct each PCF tap's depth and use the exact nominal nonzero bilinear footprint from fract(sample_uv/texel-0.5), plus8*f32EPSILON depth precision. Exact center phases omit zero-weight far neighbours. No global bias increase is used on valid receivers; this preserves close contacts. Effective offsets follow clamped sample UVs. Three-by-three filtering/casting, camera policy and uniform ABI stay intact. Qualia viewport/mod.rs directly reexports the provider catalog, so native and Portal share the fix.

Source files under C:/github/etalon: crates/etalon-render/src/shaders/{mesh.wgsl,mod.rs,shadow_receiver.wgsl}; src/{shadow_math.rs,shadow_receiver.rs,shadow_receiver_tests.rs,shadows.rs}; CHANGELOG.md. New CPU reference is zero-heap and focused on provider math. Tests cover analytic sloped planes and real/nearby occluders over resolutions512/2048, derivative scales0.001..1000, fractional phases0/.00001/.25/.5/.75/.99999; singular/grazing/nonfinite fallback; and complete production-shader Naga validation/uniformity.
